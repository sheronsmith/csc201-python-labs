# Python Projects

These are Python programs I made for my computer class in fall 2026.

## What's in here

| File | What it does | What I learned |
|---|---|---|
| `temperature_graph.py` | Makes a bar graph of how hot it got each day for a week in Spartanburg, SC. I used real weather data from Open-Meteo. | How to draw shapes and use real data |
| `this_old_man.py` | Prints all 10 parts of the song "This Old Man." I made one function and used it 10 times so I didn't have to write the same thing over and over. | How functions work |
| `valid_date.py` | You type a day, month and year, and it tells you if that date is real. It even knows about leap years. | How to make the program choose between things |
| `class_standing.py` | You type how many credit hours you have, and it tells you if you're a freshman, sophomore, junior or senior. If you type something weird, it won't crash. It just shows a nice message. | How to handle bad typing |
| `gcd.py` | Finds the biggest number that goes into two numbers evenly. It works with negative numbers and zero too. | How to use a loop that keeps going until it's done |

Each program has labels that say what kind of data goes where, so a tool called mypy can check my work.

## How to run them

You need Python 3.9 or newer. Then type:

```
python gcd.py
```

For `temperature_graph.py`, you also need a file called `graphics.py` (made by John Zelle) in the same folder. You can get it from the [Python Programming book site](https://mcsp.wartburg.edu/zelle/python/).
